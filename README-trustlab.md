## 引擎 API（`window.TLLM`）

```js
const LM = new TLLM.TinyLM(window.TL_CORPUS, 4);   // 字符级 4-gram

// 采样：真实 softmax(logits/T) + top-p + mulberry32 定种子
LM.generate({ prompt, len, temperature, topP, seed })
  // → { text, lastTop }  lastTop = 最后一步 top-5 候选（含水印绿标记）

// 水印：Kirchenbauer 绿/红名单方案的字符版
LM.embed({ prompt, len, seed, delta, gamma, key })  // 嵌入（偏向绿名单）
LM.detect(text, { key, gamma })                     // → { n, k, frac, z }
  // z = (k − γn) / sqrt(nγ(1−γ))，嵌入与检测共用同一哈希判定

// 内部件也可单独用
TLLM.mulberry32(seed); TLLM.fnv1a(str);
LM.nextDist(ctx, opts)   // 下一步完整候选分布（模块 3 的概率条用）
```

## 设计要点（为什么它"小而真"）

- **语料即伏笔**：六个主题块（月球土壤/深海热泉/金属晶体/天文观测/人工智能/测量误差）
  刻意共用句式框架（"研究表明…""换言之…""在…环境中…"）。高温采样时主题互相串线，
  产出"语法通顺、事实混搭"的文本——这正是幻觉的重组机理，不是演出来的。
- **黄金句加权**：`月球土壤的主要成分是硅酸盐矿物…` 在语料中出现 3 次，
  保证 T=0.3 时 argmax 稳定走月球答案（首版曾被深海块抢走，已修）。
- **定种子**：同参数永远同输出（fnv1a 哈希可验），支撑全站"可复现的失效"按钮。
- **温度上限 1.2**：字符级 T>1.2 会退化为字符沙拉而非"流利的胡话"，教学效果变差。
